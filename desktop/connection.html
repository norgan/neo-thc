Desktop connection

Standalone keeps inventory and discovery on this computer. Remote mode uses your chosen server for storage and discovery; playback-device checks stay on this desktop.

Without Remember, the token is kept only for this session and the next launch is standalone. It is never sent to the web renderer.

Use normal certificate verification, or select the CA that issued your server certificate. There is no certificate bypass.

A connection change stops this desktop's active local work. Remote jobs belong to the server and can be cancelled there.
