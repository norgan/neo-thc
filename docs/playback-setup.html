Set up NEO playback diagnosis once

This companion runs only when you press Capture on a YouTube or Netflix tab. It uses the browser's active-tab permission and standard video measurements. It does not read passwords, cookies, video titles, URLs, media or other browsing history.

  1. In desktop NEO, use Settings → Open browser companion folder. In browser NEO, download the companion ZIP from Playback and extract it.
  2. In Edge open edge://extensions, or in Chrome open chrome://extensions.
  3. Enable Developer mode, choose Load unpacked, and select the browser-companion folder (or extracted neo-playback-companion folder) containing manifest.json. Review the requested active-tab, scripting and session-storage permissions.
  4. Pin NEO THC Playback Companion to the browser toolbar.

Capture a problem

  1. Play the affected YouTube or Netflix video in that browser.
  2. Press the companion toolbar button, then Capture this playback. Keep the video visible while the bounded capture runs. Stop is available.
  3. Download the JSON report. In NEO → Playback, import it, review it and save it to the selected collector.
  4. Use Read device and Wi-Fi evidence during the problem on the same playback computer. In remote mode, NEO desktop reads this computer while Internet/discovery checks run on the server.

The extension is supplied as reviewable unpacked source; it is not yet published in a browser store. Installation is your explicit browser action. No extension is installed automatically. Remove it from the extensions page at any time. Reports remain in browser session storage until that browser session ends or another capture replaces them. Downloaded reports remain where you save them.

Resolution means decoded video dimensions. Protected playback may hide some counters; unknown is shown explicitly. A capture cannot determine Netflix plan eligibility, HDR/display compliance or a TV's health. Short CPU/Wi-Fi snapshots and Internet tests are supporting evidence, not proof of a root cause.
